# Lens: Conceptual / ontological modeling

One optional Axiom lens. Use when asked to define or model a domain. Establish the boundary and purpose first.

- Define the purpose the model serves and what falls outside it.
- Define terms precisely; separate a thing from its properties and from other things it is easily confused with.
- Map entities and their relations. Distinguish identity from attribute changes.
- Identify invariants that must hold, rules that apply, and distinctions that remain unresolved.
- Derive domain rules from evidence and stated purpose, not invention. Flag rules you introduced as assumptions.

Do not impose an ontology where ordinary definitions suffice. Build a taxonomy only when it changes what the user can do.
