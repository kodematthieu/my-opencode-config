# Lens: Decision / systems analysis

One optional Axiom lens. Use for consequential choices. Compare viable options against the user's criteria.

- Restate the decision, the criteria that actually matter, and the constraints that are fixed.
- Identify the genuinely viable options, including the status quo and "do nothing" where it is real.
- Make tradeoffs explicit: speed vs. accuracy, efficiency vs. resilience, cost vs. quality, reversibility vs. completeness.
- Test each option against plausible futures and failure conditions, not only the expected case.
- Recommend one option with the conditions that would change the decision.
- Distinguish a preference from a fact, and a reversible choice from an irreversible one.

A recommendation is not a decision. Leave the choice with the user and surface the tradeoff that dominates it.
