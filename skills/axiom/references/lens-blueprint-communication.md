# Lens: Blueprint / communication

One optional Axiom lens. Use when asked to document or visualize. Select a useful artifact rather than producing all of them.

Useful artifacts include a decision record, taxonomy, causal map, state model, sequence or flowchart, or a structured comparison table.

Mermaid diagrams and formal schemas are optional formats, not defaults. Keep artifacts no larger than the decision they support; state what the artifact deliberately omits.
